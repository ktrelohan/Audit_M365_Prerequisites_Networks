🎯 Why this repository?

When deploying Microsoft 365 or Microsoft 365 Copilot, it is always better to discover before going into production that a proxy, firewall, or network rule is preventing certain services from working properly.

That is why I created several PowerShell tools and scripts to validate network prerequisites and test connectivity to the various Microsoft endpoints before making the services available to users.

I’m sharing them here so they can also be useful to the Microsoft 365 community.

To develop these tools, I primarily relied on the following official Microsoft documentation:

Microsoft 365 URLs and IP address ranges
Microsoft 365 Copilot requirements
Microsoft 365 Copilot endpoints to add to your allowlist

My goal is simple: provide a quick and straightforward diagnostic approach to identify connectivity issues before they impact users.


🎯 Pourquoi ce dépôt ?

Lors d’un déploiement de Microsoft 365 ou de Microsoft 365 Copilot, il vaut mieux découvrir avant le passage en production qu’un proxy, un pare-feu ou une règle réseau empêche certains services de fonctionner correctement.

J’ai donc créé plusieurs outils et scripts PowerShell permettant de vérifier les prérequis réseau et de tester l’accessibilité des différents points de terminaison Microsoft avant de mettre les services à disposition des utilisateurs.

Je les partage ici afin qu’ils puissent également être utiles à la communauté Microsoft 365.

Pour développer ces outils, je me suis principalement appuyé sur les documentations officielles Microsoft suivantes :

Microsoft 365 URLs and IP address ranges
Configuration requise pour Microsoft 365 Copilot
Points de terminaison à autoriser pour Microsoft 365 Copilot

Mon objectif : disposer d’un diagnostic simple et rapide permettant d’identifier les problèmes de connectivité avant qu’ils n’impactent les utilisateurs.
